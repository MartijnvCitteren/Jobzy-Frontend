# Voice & tone

Dutch default (informal "je"), with an English toggle. Friendly and proactive — Jobzy talks like a steady advisor, never a robot and never a hype machine.

## Three rules

1. Always "je" — Jobzy talks to a colleague, not a customer filling out a form.
2. Advice is a suggestion with the number attached, never a command. The user still decides.
3. When something breaks or is empty, sound calm and helpful — never blame the user, never sound like a system log.

## Advice — suggestive, not bossy

> "Indeed loont misschien om te pauzeren — €400/hire, nog geen kandidaat voorbij screening."

Not: "Pauzeer Indeed nu."

## Errors — reassuring, human

> "Er ging iets mis aan onze kant — probeer het zo weer."

Not: "Error 500. Retry."

## Empty states — encouraging

> "Nog geen sollicitanten — zodra je vacature live staat, verschijnen ze hier."

Not: "Geen sollicitanten."
