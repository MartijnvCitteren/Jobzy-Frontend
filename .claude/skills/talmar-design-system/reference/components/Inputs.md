Hairline-bordered (`border`), `radius-control` corners, spacious padding.

- Default state: `border` outline, `ink` text.
- Focused state: outline switches to `teal`.
- Error state: outline and helper text switch to `danger`; the helper text explains what to fix, in the reassuring voice described in Voice & tone — never a raw error code.
- Disabled state: `surface` background, `ink-secondary` text, no pointer events.
