Flat, `radius-control` (10px) corners, generous padding — comfortable density, not a dense data table.

- Use **Primary action** (`teal` fill, `on-teal` text) for the one confident action on a screen.
- Use **Secondary** (`teal` outline and text on `surface`) for a supporting action alongside a primary.
- Use **Ghost / text** (`teal` text, no border or fill) for the lowest-emphasis action — e.g. an inline action inside a card.
- Use **Reject candidate** (`danger` fill, `on-danger` text) only for the destructive reject action, never for anything else, so it stays visually rare and meaningful.
- Disabled buttons use `border` for background and `ink-secondary` for text, and drop pointer events.
