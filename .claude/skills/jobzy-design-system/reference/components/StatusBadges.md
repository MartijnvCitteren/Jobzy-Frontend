Every status pairs a distinct shape with its color — never color alone — so the set stays deuteranopia/protanopia-safe by construction.

- **Passed screening** — circle + `status-passed` (`teal`).
- **Needs attention** — square + `status-attention` (`sand`).
- **Rejected** — triangle + `status-rejected` (`danger`).
- **New insight** — diamond + `status-insight` (`violet`). Reserve this one for advice and genuinely new information — see the Principles section of the brand book.
